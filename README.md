## Features

- **Terminal-inspired design** — dark GitHub-style theme, monospace accents, terminal windows with prompt-style section headers (`root@pandey:~$ cat about.txt`)
- **Interactive terminal** — type `help` and try `about`, `skills`, `projects`, `contact`, `github`, `clear`
- **Typewriter animation** — rotating professional roles in the hero
- **GSAP animations** — smooth scroll-triggered reveals
- **Fully responsive** — mobile hamburger menu, adapts from phone to desktop
- **Single-file build** — the whole site is one `index.html` (CSS and JS inlined and minified), so it loads fast anywhere

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- [GSAP](https://gsap.com/) + ScrollTrigger + TextPlugin for animations
- Google Fonts (Outfit, Fira Code) and Font Awesome icons
- No build tools, no framework — just static files
